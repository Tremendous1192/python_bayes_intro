ただし、`sample-notebooks/6_3_IRTによるテスト結果評価_GPU版.ipynb` と `sample-notebooks/書籍評価.ipynb` は移植対象外とし、本編11本・参考4本の計15本を対象とする。

marimo は VS Code Extension を使って、既存のVS Codeウィンドウ上で編集する。
